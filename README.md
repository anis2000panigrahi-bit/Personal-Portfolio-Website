## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/anis2000panigrahi-bit/Personal-Portfolio-Website.git
```

### 2. Open the Project

```bash
cd Personal-Portfolio-Website
```

Open the project folder in **VS Code**.

### 3. Run the Website

You can open `index.html` directly in your browser.

For a better development experience, use the **Live Server** extension in VS Code and click:

```text
Go Live
```
